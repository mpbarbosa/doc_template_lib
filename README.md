# doc_template_lib

**doc_template_lib** is a collection of reusable Markdown guide templates for architecture and AI-assisted development conventions. This repository is designed to be consumed by other projects as reference material for best practices in software architecture, documentation, and AI integration.

## Features

- Actionable, single-principle Markdown guides
- Cross-referenced documentation to avoid duplication
- Ready-to-use templates for clean architecture, code quality control,
  high cohesion, low coupling, lightweight DDD, mobile-first design,
  referential transparency, and unit testing
- Consistent structure and style for easy integration

## Getting Started

1. Clone or download this repository.
2. Copy the relevant Markdown guides into your project’s documentation directory.
3. Reference or adapt the guides as needed for your team or project.

## Documentation Structure

- Each guide focuses on a single principle or subject area.
- All guides are located at the repository root for easy discovery.
- See [GETTING_STARTED.md](docs/GETTING_STARTED.md) for more details.
