# Getting Started

Welcome to **doc_template_lib**!

## What is this?

A library of reusable Markdown documentation templates for software architecture and AI-assisted development.

## How to Use

1. **Clone or Download:** Get the repository files.
2. **Select Guides:** Choose the guides relevant to your project.
3. **Copy & Reference:** Place them in your project’s documentation directory.
4. **Customize:** Adapt the content to fit your project’s needs.
